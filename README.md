# EmergSOS Lite

Mobile safety alert app for students.

## Tech stack

- React Native
- Expo SDK 54
- Firebase Authentication
- Cloud Firestore
- Expo Location
- React Navigation
- Expo Go

## Run

```bash
npm install
npx expo start -c
```

## Firebase setup

Enable:

- Authentication > Email/Password
- Firestore Database
- Firestore rules from firestore.rules

## Main features

- Register / Login / Logout
- Emergency contacts CRUD
- SOS button hold 3 seconds
- GPS location
- Google Maps URL
- Share alert message
- SOS history
- Mark as safe
- Fake call
- Danger report/list
